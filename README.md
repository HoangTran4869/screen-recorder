# Quay Màn Hình

Ứng dụng quay màn hình nhẹ, dễ dùng cho Windows 10/11.

## Tải về
Vào trang https://github.com/HoangTran4869/screen-recorder/releases/latest → tải **QuayManHinh.zip** → giải nén → bấm đúp **Mo-QuayManHinh.bat**.

## Cách dùng
- **⏺ Quay**: bắt đầu quay (có đếm ngược 3 giây).
- **⏸ Tạm dừng / ▶ Tiếp tục**: tạm dừng rồi quay tiếp, video vẫn là 1 file.
- **⏹ Dừng & Lưu**: lưu video MP4 vào thư mục `Videos\Quay man hinh`.
- **Vùng quay**: Toàn màn hình, hoặc Chọn vùng (kéo chuột chọn khung, Esc để hủy).
- **Micro**: chọn micro để thu giọng. Dùng iPhone làm micro: cài WO Mic (https://wolicheng.com/womic/), kết nối xong bấm **↻ Tìm lại** rồi chọn **WO Mic Device**.
- **Nổi bật chuột**: giữ phím đã chọn (mặc định Ctrl) → hiện vòng tròn vàng / đèn rọi quanh chuột. Thả phím là tắt.
- **Hiệu ứng khi bấm chuột**: vòng đỏ (chuột trái), xanh (chuột phải).
- **Ẩn bảng này khỏi video**: bảng điều khiển không bị quay vào video.
